# Product Roadmap

## Phase 1 - Baseline and audit

- Confirm current builds, tests, Docker services and migrations.
- Audit every route and module against the real UI.
- Resolve documentation drift and stale tests.
- Define role capabilities and acceptance criteria.

## Phase 2 - Core workflow

- Simplify ticket intake and status transitions.
- Make approval, repair, delivery and closure explicit.
- Validate inventory consumption from tickets.
- Align invoice creation and payment flows.

## Phase 3 - Quality and experience

- Add backend unit and integration coverage.
- Add Angular component tests and browser E2E tests.
- Review accessibility, responsive behavior and error states.
- Replace generic or inconsistent UI patterns with a coherent product design system.

## Phase 4 - Operational readiness

- Prepare production Docker images and deployment configuration.
- Add backups, observability, audit logs and recovery procedures.
- Restrict CORS and finalize domains only after the deployment target is selected.
- Run a release checklist before the first production deployment.

## Deferred decisions

Power BI, chatbot, SMS and other integrations remain deferred until the core workflows, roles and operational controls are stable.
